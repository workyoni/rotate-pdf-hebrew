# rotate-pdf-hebrew
### עברית  כלי Windows ליישור אוטומטי של קובצי PDF בעברית (בודדים או תיקיות) עם תצוגה מקדימה לסיבוב ידני של עמודים שפוספסו, ללא צורך בידע טכני.  ### English  Windows app that auto-rotates Hebrew PDFs (single files or folders) with a visual preview for manual rotation of missed pages—no tech skills needed.
